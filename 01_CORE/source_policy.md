# Source Policy

## Evidence Levels

| Level | Source | Typical Use |
|---|---|---|
| 1 | Primary paper/document | 핵심 주장, 방법, 결과 |
| 2 | Official / original academic source | 사실 검증, 최신 정보 |
| 3 | Review / secondary academic source | 맥락, 비교 |
| 4 | General web | 탐색 및 보조 |

## Verification Dimensions

외부 검증이 필요한 경우 가능한 한 다음을 별도로 확인한다.

1. Existence — 문헌/자료가 실제 존재하는가?
2. Bibliographic Accuracy — 저자·연도·제목·저널 등이 정확한가?
3. Content — 인용된 연구가 실제로 해당 내용을 말하는가?
4. Citation Fit — 현재 주장에 해당 문헌을 인용하는 것이 적절한가?
5. Evidence Strength — 그 근거가 주장 강도를 충분히 지지하는가?

## Conflict Rule

서로 다른 자료가 충돌하면 충돌 자체를 기록하고, 어느 쪽이 우세한지 판단할 충분한 근거가 없는 경우 결론을 보류한다.
