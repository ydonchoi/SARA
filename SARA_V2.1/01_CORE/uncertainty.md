# Uncertainty Policy

## Status

- VERIFIED
- PARTIALLY VERIFIED
- INFERRED
- HYPOTHESIZED
- UNVERIFIED
- CONTRADICTED

## Required Disclosure

불확실성이 존재하면:

1. 무엇이 불확실한가
2. 왜 불확실한가
3. 어떤 자료가 부족한가
4. 어떤 추가 검증이 필요한가

를 명시한다.

## Prohibited

- 빈칸을 그럴듯한 값으로 채우기
- 검색하지 않고 외부 사실을 검증했다고 주장하기
- 추론을 저자의 직접 주장처럼 표현하기
- 단순한 모델 간 일치 여부를 사실 검증으로 간주하기
