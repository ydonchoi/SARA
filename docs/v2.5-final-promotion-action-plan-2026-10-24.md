## Priority 1 — Prove real runtime integration and safe operations

### P1.1 Connect the actual dialogue host and providers — NOT EVIDENCED

The CLI and callable route are present. The deployment's real host dialogue
loop, judgment model, verifier, credentials and transport are not configured in
this repository. Test the production adapters in a controlled environment for
no-inference, inference, ambiguous/unbound claim, malformed output, timeout and
partial failure.

**Exit evidence:** redacted request/result artifacts, provider/model revisions,
timeout behavior, failure-path records, and proof that only current-turn bound
claim IDs are routed. Judgment and telemetry must remain separate from evidence
and claim truthfulness.

### P1.2 Define and test provenance operations — NOT EVIDENCED

Specify storage, retention, backup/recovery, reviewer authentication and
authorization. Exercise tampering, duplicate events, stale bindings, interrupted
writes and replay against the selected deployment store. The in-memory/hash-chain
prototype and local tests do not establish production durability or identity.

**Exit evidence:** reviewed operations/security contract and deployment-level
test artifacts showing unauthorized/stale transitions fail closed.

## Priority 1 — Freeze the evaluation before collecting scores

### P1.3 Ratify the protocol and adjudicate the dataset — BLOCKED ON REVIEWERS

`v2.5-evaluation-protocol-v0.1.md` remains a draft: thresholds and independent
reviewer assignments are not approved. Recruit two independent reviewers and a
disagreement adjudicator, freeze dataset/version/split hashes, rubric, exclusions,
primary outcomes, uncertainty method and acceptance thresholds before scoring.
Keep synthetic Preflight labels separate from the adjudicated set.

**Exit evidence:** dated approval/preregistration, reviewer roles, frozen dataset
and two independent annotations per scored case with resolved disagreements.

### P1.4 Execute paired baseline comparison — BLOCKED ON P1.3

Run v2.3, v2.4 without inference-trigger routing and v2.5 with routing on the
same frozen cases and equivalent conditions. Preserve raw outputs, configurations,
retries, failures, exclusions, latency and cost. Report metric numerators,
denominators and uncertainty; do not use the local stub latency table as this
comparison.

**Exit evidence:** reproducible run artifacts and a report scored against the
predeclared thresholds, including safety violations and failure examples.

- Local performance numbers use deterministic stub providers and do not include
  model, verifier, network or database latency.
- Statement/branch coverage has not been measured (`coverage` and `pytest-cov`
  are unavailable in the active Python environment).
