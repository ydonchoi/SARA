## Priority 1 — Prove real runtime integration and safe operations

### P1.1 Connect the actual dialogue host and providers — ADAPTER IMPLEMENTED; LIVE PROOF PENDING

The standard-library adapter now supports OpenAI API, Anthropic Messages,
Gemini generateContent and OpenAI-compatible endpoints. Request/response mapping
and CLI routing are tested with stub transports. This sandbox blocks localhost
TCP and external API access, so the default socket transport has not been tested
against a live service. No live provider credentials or host dialogue loop are
configured. A missing source verifier deliberately leaves the result
`UNVERIFIED`. Configure a real provider and verify no-inference, inference,
ambiguous/unbound claim, malformed output, timeout and partial failure.

**Exit evidence:** redacted request/result artifacts, provider/model revisions,
timeout behavior, failure-path records, and proof that only current-turn bound
claim IDs are routed. Judgment and telemetry must remain separate from evidence
and claim truthfulness.

### P1.2 Define and test provenance operations — NOT EVIDENCED

Specify storage, retention, backup/recovery, reviewer authentication and
authorization. Exercise tampering, duplicate events, stale bindings, interrupted
writes and replay against the selected deployment store. The in-memory/hash-chain
prototype and local tests do not establish production durability or identity.

**Exit evidence:** reviewed operations/security contract and deployment-level
test artifacts showing unauthorized/stale transitions fail closed.
